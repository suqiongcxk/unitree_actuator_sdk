一、RS-485 接线（单路）
═══════════════════════════════════════════════════════════════════════════════

  ┌──────────────────┐       ┌───────────────┐       ┌──────────────────┐
  │   Orange Pi 5    │       │  RS-485 模块   │       │   GO-M8010-6     │
  │                  │       │  (MAX485等)    │       │                  │
  │ UART4_M2 TX ─────┼──────→│ DI             │       │                  │
  │ UART4_M2 RX ─────┼←──────│ RO             │       │                  │
  │ GPIO1_D7 (DE/RE)─┼──────→│ DE + RE        │       │                  │
  │                  │       │                │       │                  │
  │                  │       │ A ─────────────┼──────→│ RS-485+          │
  │                  │       │ B ─────────────┼──────→│ RS-485-          │
  │ GND ─────────────┼──────→│ GND            │       │ GND              │
  └──────────────────┘       └───────────────┘       └──────────────────┘

  GPIO1_D7 = 高电平 → TX 模式（发送）
  GPIO1_D7 = 低电平 → RX 模式（接收）

  ⚠ 电机供电 24-48V DC，使用独立电源，勿从开发板取电。

═══════════════════════════════════════════════════════════════════════════════
二、GPIO 芯片映射
═══════════════════════════════════════════════════════════════════════════════

  /dev/gpiochip0  →  GPIO0_A0 ~ GPIO0_D7   (GPIO0  ~ GPIO31)
  /dev/gpiochip1  →  GPIO1_A0 ~ GPIO1_D7   (GPIO32 ~ GPIO63)
  /dev/gpiochip2  →  GPIO2_A0 ~ GPIO2_D7   (GPIO64 ~ GPIO95)
  /dev/gpiochip3  →  GPIO3_A0 ~ GPIO3_D7   (GPIO96 ~ GPIO127)
  /dev/gpiochip4  →  GPIO4_A0 ~ GPIO4_D7   (GPIO128 ~ GPIO159)

四、四路总线引脚对应表
═══════════════════════════════════════════════════════════════════════════════

  总线  串口设备      Overlay        TX 引脚        RX 引脚        DE/RE 引脚     chip:line    全局GPIO
  ────  ────────────  ────────────   ────────────   ────────────   ────────────   ───────────   ────────
   A     /dev/ttyS4    uart4-m2       GPIO1_B2       GPIO1_B3       GPIO1_D7       chip1:31      63
   B     /dev/ttyS6    uart6-m1       GPIO1_A0       GPIO1_A1       GPIO1_A7       chip1:7       39
   C     /dev/ttyS7    uart7-m2       GPIO1_B4       GPIO1_B5       GPIO1_A3       chip1:3       35
   D     /dev/ttyS0    uart0-m2       GPIO4_A4       GPIO4_A3       GPIO4_A5       chip4:5       133

  说明:
  - TX/RX 引脚由设备树 overlay 固定分配，不可更改。
  - DE/RE 引脚为 RS-485 方向控制（GPIO 输出模式），高电平=TX，低电平=RX。
  - MotorController / MotorBus 构造函数用全局 GPIO 编号；
    ParallelBus / MultiBusController 用 chip:line 格式。
  - ⚠ 总线 B 使用 UART6_M1 (非 M2)，因 Orange Pi 5 Pro 40-pin 排针上
    UART6_M2 引脚未引出；总线 D 用 UART0_M2 因 UART8 引脚未引出。

═══════════════════════════════════════════════════════════════════════════════
五、引脚复用说明 (Pinmux)
═══════════════════════════════════════════════════════════════════════════════

  RK3588 同一外设可映射到不同物理引脚，由设备树 overlay 配置。
  本工程使用的四路 UART 及其引脚:

    UART4_M2:  TX = GPIO1_B2 (42),   RX = GPIO1_B3 (43)
    UART6_M1:  TX = GPIO1_A0 (32),   RX = GPIO1_A1 (33)
    UART7_M2:  TX = GPIO1_B4 (44),   RX = GPIO1_B5 (45)
    UART0_M2:  TX = GPIO4_A4 (132),  RX = GPIO4_A3 (131)

  启动配置 (/boot/orangepiEnv.txt):
    overlays=uart4-m2 uart6-m1 uart7-m2 uart0-m2

六、编译
═══════════════════════════════════════════════════════════════════════════════

  依赖:
    - cmake, g++ (C++14)
    - lib/ 目录下的 libUnitreeMotorSDK_Arm64.so (ARM64) / _Linux64.so (x86)

  ════════════════════════════════════════════════════════
  5.1 两阶段构建模型（重要）
  ════════════════════════════════════════════════════════

    cmake ..    → 生成阶段：读取 CMakeLists.txt，检测系统环境，
                  生成 Makefile（构建规则文件）
    make        → 编译阶段：按 Makefile 规则，调用 g++ 编译源码

  ════════════════════════════════════════════════════════
  5.2 何时只需 make（只改源码）
  ════════════════════════════════════════════════════════

    ✓ 修改了 .cpp / .h 文件内容
    ✓ 改了函数实现、变量、逻辑
    
    直接执行:  make -j$(nproc)
    make 会自动检测改动，只重编译变化的部分，很快。

  ════════════════════════════════════════════════════════
  5.3 何时需要重新 cmake ..（改了构建配置）
  ════════════════════════════════════════════════════════

    ✓ 修改了 CMakeLists.txt（添加/删除源文件、改编译选项等）
    ✓ 新增了 .cpp 文件需要加入编译
    ✓ 切换了编译环境（如从 x86 换到 ARM64）

    需要:  cmake .. && make -j$(nproc)

  ════════════════════════════════════════════════════════
  5.4 编译命令
  ════════════════════════════════════════════════════════

    首次搭建:
      cd /home/orangepi/unitree_actuator_sdk/build
      cmake ..
      make -j$(nproc)           # -j$(nproc) 使用所有 CPU 核心并行编译

    日常改代码后:
      cd /home/orangepi/unitree_actuator_sdk/build
      make -j$(nproc)           # 不需要再 cmake ..

    单独编译某个目标:
      make example_usage        # 单电机四模式演示
      make example_multi_bus    # 多路并行总线演示

  其他可用目标:
    make motor_test             → Orange Pi 版电机测试
    make example_goM8010_6_motor → 通用 M8010-6 示例
    make changeID               → 修改电机 ID

  ════════════════════════════════════════════════════════
  5.5 运行
  ════════════════════════════════════════════════════════

    sudo ./example_usage
    sudo ./example_multi_bus
