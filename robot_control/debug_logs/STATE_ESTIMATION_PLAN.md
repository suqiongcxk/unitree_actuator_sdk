# 四足机器人状态估计完善计划

本文档用于逐步完善状态估计链路。每一步都必须先完成代码实现、离线/干运行测试和实机静态验证，再进入下一步；在 NN 观测定义尚未与训练代码完全一致前，不允许驱动真实电机运行 NN 策略。

## 当前基线

- JY901S 使用 I2C1_M4，六轴融合模式（加速度计＋陀螺仪）。
- IMU 与机体采用右手坐标系：X 向前、Y 向左、Z 向上。
- 实机方向已确认：左侧下沉 Roll 为负，头部下沉 Pitch 为正，向左转 Yaw 为正。
- 四元数寄存器和缩放已修正，静止/运动时模长约为 1。
- `PassthroughEstimator` 目前仅直通 IMU、电机反馈；位置和线速度固定为零，接触状态固定为 false。
- 当前 48 维 NN 观测布局仍是占位定义，必须以训练代码为最终依据。

## Step 1：四元数归一化、方向和失效检查

### 工作内容

- 检查四元数四个分量是否为有限值（拒绝 NaN/Inf）。
- 检查原始模长是否处于合理范围，随后归一化。
- 处理相邻帧 `q` 与 `-q` 的符号连续性。
- 确认 JY901S 输出是 `body → world` 还是 `world → body`。
- 增加 IMU 数据超时、连续读取失败和无效姿态保护。

### 验收标准

- 水平和缓慢转动时，归一化后 `|q|` 接近 1。
- 静止时四元数无随机符号翻转。
- 拔掉 IMU 或注入非法值时，状态被标记为无效，NN 不再下发新动作。

- [x] 已完成（代码、纯软件测试、实机姿态方向及 IMU 断连失效验证均通过）

## Step 2：陀螺仪静态零偏校准与低通滤波

### 工作内容

- 上电静止采样，计算 X/Y/Z 三轴零偏。
- 校准阶段检测机器人是否确实静止，运动时拒绝保存零偏。
- 原始角速度减去零偏后进行低延迟低通滤波。
- 增加异常突跳、量程和有限值检查。
- 保持单位为 `rad/s`，坐标系为机体坐标系。

### 验收标准

- 静止时三轴角速度长期接近零。
- 缓慢转动时方向正确、响应连续，无明显过度延迟。
- 校准期间移动 IMU 能被检测并报告失败。

- [x] 已完成（代码、纯软件测试、实机静态零偏、运动拒绝校准及三轴低通响应均通过）

## Step 3：投影重力方向实机验证

### 工作内容

- 使用归一化四元数计算机体坐标系下的单位重力方向。
- 根据 Step 1 的四元数方向决定是否使用共轭。
- 将投影重力计算从 NN 输入拼装中移到状态估计层，避免重复或不一致实现。
- 检查投影重力有限性和模长。

### 验收标准

- 水平时投影重力约为 `[0, 0, -1]`（必须与训练环境一致）。
- 左右、前后倾斜时各分量变化方向与训练环境一致。
- 投影重力模长稳定接近 1，Yaw 转动不会显著改变它。

- [x] 已完成（纯软件测试和 IMU 实机方向测试均通过）

## Step 4：关节位置、速度顺序及正负号验证

### 工作内容

- 确认 12 个状态下标与 motor ID、腿序、训练关节序完全一致。
- 将编码器角度统一转换为 URDF/训练坐标系关节角。
- 对位置和速度应用相同的减速比与方向映射。
- 检查零点偏置、单位、错误码和反馈时间戳。
- 编写逐关节离线/低风险验证输出。

### 验收标准

- 单独转动任一关节时，只有预期观测下标发生主要变化。
- 关节朝 URDF 正方向运动时，位置和速度均为正。
- 默认站立姿态与训练环境中的默认关节位置一致。

- [ ] 代码审计与纯软件测试已完成；等待逐关节低风险实测

## Step 5：时间戳和状态有效性保护

### 工作内容

- 为 IMU、电机反馈和估计输出维护单调时钟时间戳。
- 正确计算并限制估计周期 `dt`。
- 增加 IMU 数据年龄、电机数据年龄、连续失败计数和整体 `valid` 状态。
- 定义超时阈值和降级策略。
- 无效或过期状态不得进入新的 NN 推理/电机指令下发。

### 验收标准

- 模拟 IMU 或任一电机反馈中断时，能在设定时间内检测。
- 时间戳倒退、异常 `dt` 和部分反馈缺失不会产生异常控制指令。
- 故障时统一转入已定义的安全保持或阻尼退出流程。

- [x] 已完成（纯软件测试、正常实机链路、电机反馈超时、IMU 数据流中断和 Ctrl+C 阻尼退出均通过）

## Step 6：修正 NN 的“上一帧动作”观测

### 工作内容

- 明确训练代码中的 action 定义、缩放和裁剪方式。
- 保存真正的上一帧 NN 原始动作或缩放后动作，与训练定义保持一致。
- 首帧使用训练时约定的初始化值。
- 禁止继续用 `default_pose` 冒充上一帧动作。
- 对比 ONNX 输入维度、顺序、归一化和 clipping 参数。

### 验收标准

- 逐元素对比同一输入在训练端和 C++ 端生成的 observation。
- 48 维观测的每个下标均有明确来源、单位、缩放和范围。
- 离线 ONNX 输出与训练端推理结果在允许误差内一致。

- [x] 已完成（训练端黄金向量逐元素对拍及 1483 帧实机 monitor-only 运行时日志验收均通过）

## Step 7：接触检测与机体线速度估计

### 工作内容

- 基于关节运动学、关节速度和电机力矩建立初始接触判定。
- 条件允许时接入足端力传感器，提高接触判断可靠性。
- 对支撑腿使用足端近似零世界速度约束，反推机体速度。
- 融合 IMU 加速度、腿部运动学和多足接触置信度。
- 估计机体高度，并识别打滑、腾空和落地冲击。

### 验收标准

- 静止站立时估计线速度接近零且不持续漂移。
- 抬起单腿时接触状态切换正确，不污染支撑腿速度约束。
- 手动缓慢平移机体时速度方向正确且连续。
- 打滑或无可靠支撑足时降低估计置信度，不输出虚假高可信速度。

- [x] 已完成（代码、纯软件测试、接触阈值、单/双腿卸载、速度方向、腾空及打滑降置信实机验收均通过）
